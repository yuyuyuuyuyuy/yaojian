# 药鉴 · 产品文档（PRD）

> 版本 0.3.0 ｜ 2026-09-09 ｜ 目标用户：化工药学大类大学生

## 一、产品定位

**药鉴**是一款桌面知识库问答应用：把你自己的课程资料（实验讲义、药典通则、SOP、PPT 课件、手写笔记照片等）导入后，用自然语言提问，AI 依据资料回答并**标注引用原文出处**，点击即可逐字核对——杜绝"一本正经胡说八道"。还能输入关键词一键整理出带引用的结构化复习笔记。

- 一句话：**「能查原文的课程资料问答助手」**
- 平台：Windows 10+ / macOS（未签名需右键打开一次）
- 形态：本地桌面 APP，无服务器、无云存储，数据全部本机保存

## 二、核心功能

### 1. 知识库问答（内置库 + 自建库 + 任意组合）
- **内置「药典知识库」**：开箱即用，含《中国药典》2025 年版通则整理的 10 大类演示语料（实验室基础操作 / 试剂与溶液配制 / 一般鉴别 / 一般杂质检查 / 含量测定 / 溶出度 / 微生物与无菌 / 仪器分析 / GMP / 标准与参考）。
- **自建知识库**：按课程创建（如"仪器分析""有机化学实验"），支持导入 txt / pdf / docx / pptx（单文件 ≤20MB、≤200 页）。
- **知识库任意组合**（0.2.0 新增）：聊天头部选择器可勾选**单个 / 多个 / 全部**知识库参与问答；侧边栏点库名=快速单选；切换后自动开新对话。

### 2. 引用原文对照（防幻觉核心）
- 每个结论后紧跟引用编号 [1][2]，徽章可点击；
- **点击徽章 → 自动定位到回答下方引用列表第 n 条并展开原文**（高亮提示），支持「全部展开 / 全部收起」；
- 引用条目含知识库名、文件名、相似度分数（OCR 入库内容还会标注「第N页」）；
- 检索零命中时直接回答"资料中未找到相关内容"，**不调用大模型编造**。

### 3. 拍照识字 OCR（0.2.0 新增，用户拍板）
- 手写笔记 / 课本照片 → 云端多模态识别（通义千问 VL 系列）→ 转文字；
- **识别结果可逐张校对**（对照原图修改错字、改文件名）→ 一键保存进自建知识库并自动建立索引；
- 入口：侧边栏「📷」按钮或聊天区空状态引导；支持多选、拖拽、Ctrl+V 粘贴截图；
- 识别仅供参考（手写/公式准确率有限），请对照原文校对后再入库。

### 4. 整本 OCR（扫描版 PDF）（0.2.0 新增，用户拍板）
- 无文字层的扫描版 PDF：逐页渲染 → 识别 → 生成页码级文本入库，问答引用标注「第N页」；
- 入口：知识库条目悬停「📑」按钮；页数越多耗时越长（约 3~6 秒/页），后台执行可关弹窗。

### 5. PPT 课件入库（0.3.0 新增，用户拍板）
- 直接导入 **.pptx** 课件（老 .ppt 请先用 PowerPoint 另存为 .pptx）；
- **文字型页面零费用秒级提取**（正文/表格/备注/图表数据都提取，引用标注「第N页」）；
- **图片型页面自动识别**（页内文字不足时，把页内图片送 AI 识别兜底，约 1~2 分/页）；
- 与 txt/pdf/docx 一样支持多选、整个文件夹导入，自动增量索引。

### 5. 多轮追问
- 同一对话内连续追问（"什么是重金属检查法？→它分几种方法？→第三法适用什么条件？"），结合上文理解指代。

### 6. 知识笔记（0.3.0 新增，用户拍板）
- 输入**关键词**（如"道尔顿分压定律"）→ AI 检索所选知识库相关内容 → 整理成**结构化复习笔记**：定义与概述 / 核心要点 / 公式与数据 / 易错与注意，每个结论带引用编号可点开核对原文；
- 知识库中查不到会明确告知，不编造；约 2~5 分钱/篇；
- 笔记可：**复制 / 导出 Markdown / 导出 Word / 保存到「我的笔记」/ 一键加入自建知识库**（把整理好的笔记变成复习语料参与问答）；
- 入口：侧边栏「学习工具」区的「📝 知识笔记」「📄 我的笔记」。

### 7. 首次使用引导（0.3.0 新增，用户拍板）
- 首次启动弹出**分步向导**：欢迎与 API Key → 认识知识库 → 资料入库 → 拍照识字 → 知识笔记，可随时跳过；
- 完成或跳过后不再出现；设置页「重新查看使用引导」可随时再看。

### 8. 笔记导出（用户拍板加入）
- 一键把当前对话（问题+回答+引用原文展开）导出为 **Markdown（.md）** 或 **Word（.docx）**，方便写实验报告、复习笔记；默认保存到"下载"文件夹。

### 9. 回答快捷操作（0.2.0 新增）
- 每条回答下方：**复制全文**（写报告直接粘贴）、**停止生成**（跑偏随时打断，已生成部分保留在历史）、**重新生成**（不满意重答一次，不重复记录提问）。

### 10. 会话历史（0.2.0 新增）
- 侧边栏「🕘 历史对话」：查看过往对话（标题/时间/知识库范围），点击继续聊、可删除。

### 11. 外观主题（0.2.0 新增）
- 浅色 / 深色 / 跟随系统三种外观（设置页切换），重启保持。

### 12. 侧边栏分区管理（0.3.0 新增，用户拍板）
- 常用功能按「**知识库 / 学习工具 / 系统**」三组分区管理；「学习工具」（📷拍照识字、📝知识笔记）用主题色高亮，一眼找到常用功能。

### 13. 召回调试（维护者工具）
- 设置页 →「召回调试」：输入问题查看检索命中的原文与相似度分数，可临时调 top_k 与阈值——排查"资料里有却答不出"的唯一入口。

### 14. 语料统计（维护者工具，随 A3b 加入）
- 设置页 →「语料统计」：每个知识库的数据质量台账——文档数、总块数、上次索引时间、新增/复用文件数；解析失败清单（含原因）与未进入索引的文件；每文件块数明细（块数异常少＝解析可能有问题）。
- 索引统计持久化在 `kbs/<库id>/ingest_stats.json`，重启不丢。

### 15. 自动评测（开发者工具，随 A1 加入）
- `tests/eval.py` 命令行脚本：对金标数据集（`tests/eval_dataset.json`，20 单题 + 3 组追问 + 2 拒答）跑三关评分（引用溯源 / 要点覆盖率裁判 / 拒答），产出 Markdown 报告并与上次对比标出退化题目；`--dry` 免费校验。
- 用途：改提示词、换模型、增语料后的回归验证；费用约 0.8~1 元/轮。

### 16. 设置
- 替换 API Key（内置 Key 开箱即用，可换成自己的）；对话 / 嵌入 / OCR 模型；检索参数（top_k、相似度阈值）；外观主题；费用说明与数据目录。

## 四、界面与操作流程

- **界面**：左侧深色侧边栏（三组分区：知识库列表 + 新建 / 学习工具（高亮）/ 系统），主区聊天视图（顶部知识库选择器/导出/新对话，中部消息流，底部输入框），设置页含「基本设置 / 召回调试」两个标签页。
- **典型流程**：
  1. 首次启动：5 步使用引导（可跳过，完成或跳过后不再出现）；
  2. 侧边栏「＋ 新建知识库」：命名 → 选择文件或整个文件夹（txt/pdf/docx/pptx）→ 自动复制并建立索引（进度条）；
  3. 聊天区提问 → 流式回答 → 点击 [n] 徽章定位展开原文核对；
  4. 拍照识字：侧边栏「学习工具」→「📷 拍照识字」→ 选图/粘贴 → 识别 → 校对 → 保存入库；
  5. 「📝 知识笔记」：输入关键词 → 生成带引用的结构化笔记 → 复制/导出/保存/一键入库；
  6. 「📝 导出笔记」→ 选 Markdown 或 Word → 到"下载"文件夹取文件。

## 五、数据与隐私

- **全部本地存储**：文档副本、向量索引、对话历史、设置，均在用户目录（Windows：`%APPDATA%\LabAssistant\`）。
- **联网行为**：①问答时把检索到的文档片段发送给阿里云百炼生成回答；②OCR 时把图片发送给阿里云百炼识别（页面有提示）。请勿导入涉密资料。
- 删除知识库即删除其文档副本与索引；对话历史保存在 chat.db。

## 六、费用说明

- 按量计费：每次问答约 **1~2 分钱**；拍照识字每张约 **1~2 分钱**；整本 OCR 约 0.5~2 分/页（200 页约 0.2~1 元）；PPT 图片型页面识别约 **1~2 分/页**（文字页零费用）；知识笔记每篇约 **2~5 分钱**；充值 20 元可长期使用。
- 余额查询与充值：百炼控制台 https://bailian.console.aliyun.com/
- 余额耗尽会报错，充值后即可恢复。

## 七、常见问题

| 现象 | 处理 |
|---|---|
| 双击 exe 被杀毒软件拦截 | 本项目未签名，属误报；点"更多信息→仍要运行"，或将程序目录加入白名单 |
| 启动报错缺少 WebView2 | 安装微软官方 WebView2 运行库（app 会弹窗给下载链接） |
| 回答"资料中未找到"但资料里有 | 换问法或去「召回调试」看命中分数；可调低阈值 |
| 回答细节与原文不符 | 大模型偶有发挥；正式场合以引用的原文为准（QC 合规要求人工复核） |
| 断网时提问报错 | 问答需联网；已导出的笔记与历史对话不受影响 |
| 扫描版 PDF 导入失败 | 无文字层无法直接解析：知识库条目悬停「📑」用整本 OCR 识别后入库 |
| OCR 识别不准确 | 手写/公式识别有限，属正常现象；用拍照识字界面的校对功能修正后再保存 |
| PPT 上传没反应 | 仅支持 .pptx（2007 版后格式）；老 .ppt 请先用 PowerPoint「另存为」成 .pptx |
| 知识笔记提示查不到 | 所选知识库确实没有该关键词内容（不编造）；可换关键词或先导入相关资料 |
