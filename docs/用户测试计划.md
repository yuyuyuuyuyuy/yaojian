> 版本 2.0 ｜ 2026-09-17 ｜ 0→1 流程 S11（用户测试执行准备）产出
>
> **目的**：验证 docs/需求调研文档.md 第四章的假设清单（H1~H11）。H5（口语化检索）已于 2026-09-16 离线实验完成（不成立，A7a 证伪），**剩余 10 条假设由真实用户测试验证**。

## 〇、招募话术（直接复制发群/私聊）

> 同学你好！我做了一个学习小工具「药鉴」：把课件/真题/笔记装进电脑，问什么答什么，**每个答案都能点开原文核对**，还能一键生成复习笔记和背诵卡片。现在需要 5~8 位同学帮忙试用 30 分钟，不需要任何基础，下载解压就能用。用完后填一个 2 分钟小问卷 + 点一下「使用数据」导出，答谢一瓶饮料 🧋
> 下载：https://github.com/yuyuyuuyuyuy/yaojian （Releases 下载 Windows 版 zip，解压双击 YaoJian.exe）
>
> 考研版话术（C 群专用，加一句）：特别适合考研同学——专业课资料太多翻不过来？真题考点不知道重点？来试试就知道。

## 二、任务清单（发给测试者，按顺序做）

**第一步：开箱（约 3 分钟）**
1. 解压 zip，双击 YaoJian.exe（首次启动弹引导，可跳过）；
2. 看看界面凭第一印象回答问卷第 1 题。

**第二步：核心体验（约 15 分钟）**
3. 新建知识库，导入测试包资料（我们预置一个含 3 份课件的文件夹）→ 等索引进度；
4. 输入：`检测药物内一般杂质的基础项目和合格范围是什么？` → 回答完成后**点击 [1] 徽章**看会发生什么 → 问卷第 2 题（**H1 引用核对**）；
5. 追问：`它分几种方法？` → 看能否结合上文回答（A7b 多轮指代）；
6. 问一个完全无关的问题（如 `怎么打王者荣耀上分？`）→ 观察回应；**再问一个资料外但同领域的题（`药物的降压作用机制是什么？`）** → 观察是否同样拒答 → 问卷第 3 题（**H2 拒答信任**）；
7. 知识库选择器勾选多个库，再问一题（**H3 跨库组合**）；
8. 导入一个 PPT 课件（预置测试 PPT）→ 等索引 → 问一个 PPT 里的内容（**H6 PPT 导入意愿**）；
9. 「📝 知识笔记」输入关键词 → 观察模块分类 → 勾选想要的模块生成 → 打分（**H7 笔记有用度**）。

**第三步：V0.2 功能体验（约 8 分钟）**
10. 「📷 拍照识字」拍一张手写笔记（或 Ctrl+V 截图）→ 识别 → **故意改一个错字** → 保存入库 → 问照片相关问题（**H4 OCR 校对**）；
11. 把第 9 步的笔记一键生成问答卡 → 复习 10 张卡（**H10 背诵材料**；观察防积压提示与前置引导是否出现）；
12. 设置页看「用量与费用」「使用数据」面板（观察记录）；
13. 意见反馈入口写一条任意反馈（**验证 F15 三通道，对应埋点 feedback_submitted**）。

**第四步：C 群专属（约 5 分钟，仅考研生）**
14. 普通模式导入 1 份真题 PDF + 1 份讲义 → 按考点提问 → 核对引用定位（**H9 考研资料整合**）；
15. 访谈探针（不给功能，纯提问）：「你现在怎么判断哪些考点是重点？」「如果有个功能：上传目标院校真题，它学风格给你出模拟题、每题答案能核对到你的资料原文，你会用吗？愿意为此付费吗？」（**H11 需求探针**）。

**第五步：收尾（约 2 分钟）**
16. 设置 → 使用数据 → 导出 → 把 JSON 文件发回（数据回收）；
17. 回答问卷第 4~10 题（付费意愿 H8、推荐分、专业背景）。

## 三、问卷模板（腾讯问卷/问卷星）

| # | 问题 | 选项 | 对应假设 |
|---|---|---|---|
| 1 | 第一印象：界面是否清晰易懂？ | 1~5 分 + 一句话 | — |
| 2 | 点击 [1] 徽章后，是否找到对应原文？感觉如何？ | 能/不能 + 信任度 1~5 | H1 |
| 3 | 它拒绝回答资料外问题时，你的感受是？ | 靠谱/机械/无所谓 + 一句话 | H2 |
| 4 | 多选知识库提问，引用里能看到不同库来源吗？ | 能/不能 | H3 |
| 5 | 拍照识字的文字准确吗？校对修改方便吗？ | 准/一般/差 + 校对体验 1~5 | H4 |
| 6 | 导入 PPT 的过程顺畅吗？平时会想把课件导入 AI 工具吗？ | 顺畅/一般/费劲 + 愿意/不愿意 | H6 |
| 7 | 生成的笔记对你有用吗？（模块勾选体验如何） | 很有用/一般/没用 + 勾选体验 1~5 | H7 |
| 8 | 问答卡复习符合你的背诵习惯吗？比自己做卡省时间吗？ | 符合/一般/不符合 + 省时 1~5 | H10 |
| 9 | 如果收费（如每学期 20 元），你愿意付费吗？ | 愿意/看情况/不愿意 | H8 |
| 10 | 你会推荐给同学吗（0~10 分）？最想改进的一点？专业背景？ | 打分 + 文字 | H8/分群 |
| 11 | **如果药鉴明天消失了，你会失望吗？**（S13 PMF 判定用，Sean Ellis 40% 法则） | 非常失望/有点失望/无所谓 | PMF 信号（≥40% 非常失望） |

## 四、假设判定标准表

| 假设 | 判定标准 | 数据来源 |
|---|---|---|
| H1 引用核对建立信任 | ≥70% 测试者第 2 题信任度 ≥4；陷阱题发现率 ≥50% | 问卷 2 + 观察记录 + 埋点（新用户前 3 次核对率） |
| H2 拒答建立信任 | ≥60% 对拒答态度正面（靠谱）；无人因拒答直接退出 | 问卷 3 + 观察 + 埋点（拒答后继续提问率） |
| H3 跨库组合有价值 | ≥50% 未提示即使用多选 | 观察 + 问卷 4 + 埋点（kb 范围类型） |
| H4 OCR 校对有效 | ≥60% 完成校对并入库 | 观察 + 问卷 5 |
| H6 PPT 导入意愿 | ≥70% 完成导入且愿意日常使用 | 观察 + 问卷 6 + 埋点（doc_imported） |
| H7 笔记有用度 | ≥60% 打分 ≥4 且愿意用于复习 | 问卷 7 + 埋点（note_generated/note_saved_to_kb） |
| H8 付费接受度 | ≥50% 愿意自费充值或自填 Key；**C 群愿意比例显著高于 A 群** | 问卷 9/10 + 埋点（key_replaced） |
| H9 考研资料整合 | ≥70% 表示明显省时 | C 群任务 14 + 访谈 |
| H10 背诵材料 | ≥60% 表示符合背诵习惯且省时 | 问卷 8 + 埋点（card_created/card_reviewed） |
| H11 个性化出题探针 | ≥50% 表达强需求则 C3 立项 | C 群任务 15 访谈 |

**观察项判定模板（决策 41 承接）**：内部验收遗留的「观察项」问题——**S11 中 3 名以上测试者独立遇到 → 升级 P1 修复；无人遇到 → 关闭（保留记录）**。

## 五、数据回收与报告

1. **问卷**：腾讯问卷导出 Excel（或截图）；
2. **埋点数据**：每位测试者「设置 → 使用数据 → 导出」的 JSON 文件（不含对话内容，保护测试者隐私）；
3. **观察记录**：任务执行中的卡壳/困惑/耗时记录（按 S10 剧本记录表格式）；
4. 回收后 Claude 负责：聚合数据 → 逐条对照判定标准表 → 更新需求调研文档（假设验证结论）→ 产出「用户测试报告」（含 H1~H11 判定表、观察项处置、设计修正清单）作为项目证明材料。

## 六、注意事项

1. 测试者电脑需 Windows 10+；杀软拦截点「仍要运行」（未签名属误报，使用说明已披露）；
2. **内置 API 额度有限**：提醒测试者按任务清单操作，每人 20 问内（F14 用量可见正好可演示）；
3. 手写照片如带小红书等水印，识别文本会包含水印内容，属正常现象，可演示校对删除；
4. 测试包资料由我们预置（3 份课件+1 个 PPT+1 份真题+1 份讲义），**不含测试者个人资料**；
5. 录屏/截图用于内部报告，不公开发布测试者信息。
