# 药鉴 · 真实用户测试计划（A2）

> 目的：验证 docs/需求调研文档.md 第四章的 8 条可测试假设（H1~H8），拿到「已落地」的真实用户证据。
> 规模：5~8 位同学（化工药学相关专业优先，兼顾 1~2 位非相关专业）；每人 20~30 分钟。
> 费用预估：每位测试者约 10~20 次问答 + 2 张照片 OCR，约 0.3~0.6 元，全部 8 人约 5 元以内。

## 一、招募话术（直接复制发群/私聊）

> 同学你好！我做了一个学习小工具「药鉴」：把课件/笔记丢进去，就能像问学霸一样提问，每个回答都能点开原文核对，绝不瞎编。现在需要 5~8 位同学帮忙试用 20~30 分钟，不需要任何基础，下载解压就能用。用完后填一个 2 分钟的小问卷即可，答谢一瓶饮料（可选）🧋
> 下载：https://github.com/yuyuyuuyuyuy/yaojian （Releases 里下载 Windows 版 zip，解压双击 YaoJian.exe）

## 二、测试任务清单（发给测试者，按顺序做）

**第一步：开箱（约 3 分钟）**
1. 解压 zip，双击 YaoJian.exe（首次启动弹 5 步引导，跳过即可）；
2. 看看侧边栏分区和聊天界面，凭第一印象回答问卷第 1 题。

**第二步：核心体验（约 15 分钟）**
3. 在聊天框输入：`检测药物内一般杂质的基础项目和合格范围是什么？`
   等回答完成后，**点击回答里的 [1] 徽章**，看看会发生什么 → 对应问卷第 2 题（H1 引用核对）；
4. 追问：`它分几种方法？` → 看它能否结合上文正确回答（H5 多轮）；
5. 问一个完全无关的问题（如 `怎么打王者荣耀上分？`）→ 观察它怎么回应（H2 拒答信任）；
6. 用聊天顶部的知识库选择器，勾选多个知识库，再问一题（H3 跨库组合）；
7. 侧边栏「学习工具」→「📝 知识笔记」，输入关键词 `重金属检查法` → 生成笔记 → 点引用核对原文（H1/H6）。

**第三步：OCR 体验（约 8 分钟，手边有笔记本/课本即可）**
8. 「📷 拍照识字」→ 选一张手写笔记照片（或 Ctrl+V 截图）→ 识别 → **故意改一个错字** → 保存到一个新知识库（H4 OCR 校对）；
9. 等索引进度走完（侧边栏绿色圆点），问一个照片内容相关的问题（H4/H6）。

**第四步：收尾问卷（约 2 分钟）**
10. 回答 H8 付费意愿 + 整体评价。

## 三、问卷模板（问卷星/腾讯问卷或直接微信群接龙）

| # | 问题 | 选项 |
|---|---|---|
| 1 | 第一印象：界面是否清晰易懂？ | 1~5 分 + 一句话 |
| 2 | 点击 [1] 徽章后，是否找到了对应原文？感觉如何？ | 能/不能 + 信任度 1~5 |
| 3 | 它拒绝回答无关问题时，你的感受是？ | 靠谱/机械/无所谓 + 一句话 |
| 4 | 多选知识库提问，引用里能看到不同库的来源吗？ | 能/不能 |
| 5 | 口语化追问（"它分几种"）它理解对了吗？ | 对/错 |
| 6 | 拍照识字的文字准确吗？校对修改是否方便？ | 准/一般/差 + 校对体验 1~5 |
| 7 | 生成的复习笔记对你有用吗？ | 很有用/一般/没用 |
| 8 | 如果这个 APP 收费（比如每学期 20 元），你愿意付费吗？ | 愿意/看情况/不愿意 |
| 9 | 你会推荐给同学吗（0~10 分）？最想改进的一点是？ | 打分 + 文字 |
| 10 | 你是什么专业？平时用 AI 学习吗？ | 文字 |

## 四、数据整理与假设判定（我来做，你回收问卷后发我）

| 假设 | 判定标准 | 对应问卷题 |
|---|---|---|
| H1 引用核对提升信任 | ≥70% 测试者第 2 题信任度 ≥4 | 2 |
| H2 拒答建立信任 | ≥70% 对拒答态度正面（靠谱） | 3 |
| H3 跨库组合有价值 | ≥70% 第 4 题「能」 | 4 |
| H4 OCR 校对有效 | 第 6 题校对体验 ≥4 | 6 |
| H5 口语化检索 | ≥80% 第 5 题「对」 | 3、5 |
| H6 语料覆盖影响满意 | 第 7 题有用 ≥60% | 7 |
| H7 QC 合规核对 | （学生版暂不测；有 QC 实习经历的同学单独加问） | - |
| H8 付费意愿 | ≥40%「愿意」+≥60% 推荐分 ≥7 | 8、9 |

## 五、测试记录与后续

- 每位测试者的问答过程会自动存在 APP 里（可在测试后导出对话作为过程证据）；
- 遇到问题让测试者走「设置 → 💬 意见反馈」提交（这本身就是反馈入口的验收）；
- 回收后我负责：汇总数据 → 更新需求调研文档（假设验证结论）→ 产出「用户测试报告」作为项目证明材料。

## 六、注意事项

1. 测试者电脑需 Windows 10+；杀软拦截时点「仍要运行」（未签名属误报）；
2. 内置 API 额度有限：请提醒测试者按任务清单操作，不要无限刷问题（每人 20 问内）；
3. 手写照片如带小红书等水印，识别文本会包含水印内容，属正常现象，可当场演示校对删除。
