# 药鉴 · 项目一页纸（2026-09-15）

> 多场景主材料：按用途裁剪——答辩侧重「技术实现与测试数据」；比赛侧重「创新性与用户价值」；求职侧重「产品思维与成果量化」。对应章节见文末。

## 一句话

**药鉴**：把课件、讲义、手写笔记装进自己电脑，问什么答什么、每个答案都能点开原文逐字核对的 AI 学习助手——查不到就明说，绝不编造。

## 问题

化工药学专业大学生在课程学习中面临三类痛点：
1. **资料多而散**：课件 PDF/PPT、扫描讲义、手写笔记格式混杂，复习时翻找低效；
2. **大模型不可信**：通用 AI 回答不标来源、时常"一本正经胡说八道"，无法用于学习与实验核对；
3. **整理成本高**：把零散资料整理成可复习的结构化笔记耗时巨大。

## 解决方案

桌面 APP（Windows，Mac 版规划中），数据全本机，直连大模型 API：

| 能力 | 说明 |
|---|---|
| 📚 资料入库 | txt/pdf/docx/pptx 直接导入；PPT 图片页自动识别；扫描版 PDF 整本 OCR；手写笔记拍照转文字（可逐张校对） |
| ❓ 知识库问答 | 内置药典知识库开箱即用 + 按课程自建多库，单个/多个/全部任选；多轮追问理解指代 |
| 📑 引用原文核对 | 每个结论带 [n] 引用，点击即定位展开原文（含页码与相似度），支持导出 Word/Markdown |
| 📝 知识笔记 | 输入关键词自动整理结构化复习笔记（定义/要点/公式/易错），可一键存回知识库当语料 |
| 🛡 防幻觉双防线 | 检索阈值挡无关领域（零命中不调大模型）+ 提示词铁律挡同领域漂移（诚实拒答） |

## 核心亮点（差异化）

1. **能核对的学习 AI**：引用逐字对照原文，把"信任"作为产品核心——实测拒答正确率 100%，无关问题绝不编造；
2. **AI 全链路**：OCR（手写/公式识别）、向量检索（多库融合）、结构化整理，一个产品闭环覆盖"资料→学习→复习"；
3. **成本极低**：每问约 1~2 分钱，整本 OCR 200 页约 1 元，学生充值 20 元可用一学期；
4. **隐私友好**：资料、索引、对话全在本机，仅检索片段发往 API。

## 关键数据（可引用）

- 金标评测（20 单题+3 追问+2 拒答）：**25/25 通过**，含引用溯源/要点覆盖/拒答三关自动评分；
- 验收体系：检索命中率≥90%、引用正确率 100%、多轮指代正确；
- 真实手写笔记照片 OCR 端到端验收通过（含公式/下标/分数识别）；
- 增量索引：文件哈希跳过未变文件，重建零重复费用；
- 开源：GitHub 公开仓库（MIT 许可）。

## 技术栈

Python + pywebview（桌面壳）｜Flask（本地后端）｜sqlite-vec（向量检索）｜阿里云百炼 qwen-plus / text-embedding-v4 / qwen3-vl（对话/向量/OCR）｜PyMuPDF / python-docx / python-pptx / Pillow（解析）｜原生 HTML/CSS/JS（前端，无构建无 CDN）。
