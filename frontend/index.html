    数据与隐私：所有文档、对话历史均保存在本机（ ）。 问答时检索到的文档片段会发送给阿里云百炼用于生成回答，请注意文档内容的合规性。
    备份与恢复：换电脑或重装系统前，先导出一份备份包（含知识库/对话/笔记，不含 API Key）。 在新电脑上导入恢复即可。恢复会覆盖当前全部数据（旧数据会保留一份在数据目录旁，误操作可找回）。
    输入问题查看检索命中的原文段落与相似度分数，用于排查「资料里有却答不出」的情况（复刻 Dify 召回测试）。
    各知识库的语料质量台账：文档数、总块数、上次索引时间、解析失败清单。导入资料后到这里核对「哪些文件没进索引、为什么」。
    药鉴在本机记录你的使用行为（问了什么题、点了哪些引用等只记行为不记内容），用于改进产品。数据只存你的电脑、绝不上传；你随时可以查看、导出或删除。

    新建知识库

    给知识库起个名字，并选择课程资料（txt / pdf / docx / pptx，可多选或整个文件夹）。PPT 仅支持 .pptx 格式（老 .ppt 请另存为 .pptx），图片型页面会自动识别文字（约 1~2 分/页）。

    🕘 历史对话

    点击对话继续聊；对话按创建时间倒序排列。

    📑 整本 OCR（扫描版 PDF）

    把无文字层的扫描版 PDF 逐页识别为文字后入库，问答引用会标注「第N页」。 每页约 0.5~2 分钱、3~6 秒，页数越多耗时越长（200 页约 10~20 分钟）。 识别期间可关闭本弹窗，任务在后台继续。

    📝 知识笔记

    输入关键词（如「道尔顿分压定律」），AI 检索所选知识库的相关内容，整理成结构化复习笔记。 每个结论带引用编号，可点击核对原文；生成约需 10~30 秒，约 2~5 分钱/篇。
